# Matthew Berger

Senior Staff Rust Software Engineer. I write production Rust at every layer of the stack, from bare-metal firmware to cloud. Founding engineer at Hyphen, where I built the food assembly robotics controls suite from zero to production in 22 months, underpinning $35M+ raised from Chipotle and Cava.

Prior production experience in aerospace imaging (Sierra Nevada Corporation) and safety-critical medical robotics (Hamilton Company). 9+ years writing Rust.

## Notable work

Currently building [Nightshade](https://github.com/matthewjberger/nightshade), a data-oriented Rust game engine with custom render graph, built-in editor, rapier3d physics, gltf asset loading, and Steam integration. It runs natively on DX12/Metal/Vulkan and in-browser via WebGPU. Live demo at [matthewberger.dev/nightshade](https://matthewberger.dev/nightshade).

Other Rust crates with 280k+ combined crates.io downloads include [freecs](https://github.com/matthewjberger/freecs) (archetype-based ECS with 48k+ downloads, design documented in a 3-part article series) and the enum2 derive macro family (230k+ combined downloads across enum2str, enum2contract, enum2egui, enum2pos, and enum2repr). Also maintain [wgpu-example](https://github.com/matthewjberger/wgpu-example), a cross-platform Rust + wgpu + egui template running on native, web, Android, Steam Deck, and OpenXR VR.
